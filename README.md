# bull-buddy

A small bull that keeps you company in Claude Code. It paces back and forth in the band above the prompt, walking steadily while Claude is idle and charging (green, quick steps) while Claude works.

Type `/bull` to hide it or bring it back.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install bull-buddy --marketplace Amitpu941/travellingBull
```

Answer `y` to add the marketplace, then pick the user scope so it loads in every session.

From a shell:

```
claude plugin install bull-buddy --marketplace Amitpu941/travellingBull
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `Amitpu941/travellingBull`, then Add plugin.
